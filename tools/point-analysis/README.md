# Read-only analysis

Run the command in the root README. Python standard library only. The parser accepts literal decimal/hex unsigned-short PROGMEM arrays, rejects unsupported expressions and invalid pairs, and never modifies inputs. Statistics separate identical XY from identical XY+laser state; segment lengths include blanking moves.

`--steps` and `--delay-ms` configure an approximate model of SymbolSender subdivision, applied independently to every array. Default 5/6 matches normal fulltexts outline parameters, not the stone, fill helpers, or playback frequency. Delay-weighted visits are a relative dwell proxy, not exposure or measured DAC dwell. No mocked hardware or synthetic test results are used.
