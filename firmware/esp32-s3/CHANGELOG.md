# ESP32-S3 firmware

## 0.1.5 — 2026-10-31

- Восемь углов 0°, 45° … 315°, шаг энкодера 45°; голубые маркеры соседние. USB angle принимает те же значения. Вписывание при 45° сохранено.
- Базовый масштаб 1.0, угол 0°. При импорте прежних профилей эти два значения сбрасываются, остальные настройки сохраняются. Сохранённый новый профиль восстанавливает осознанно выбранные значения. Формат профиля — версия 3, прежние 56 байт.
- Show пропускает контур камня и сразу начинает символы/надписи; при повторе контура тоже нет. Stone остаётся отдельной диагностикой, Frame с большой F сохранён.
- Пороги пуска/сохранения не менялись: для пуска удержать около 2 с и отпустить, от 3,5 с — сохранение. Причина сообщения о несрабатывании пуска аппаратно не подтверждена.

## 0.1.4 — 2026-10-30

- Три программы: Show / Stone / Frame + F. Большая F внутри рамки сохранена по уточнению владельца; удалены только отдельные маленькие Square и F.
- Единое меню во всех программах и при остановке: короткое нажатие — следующий параметр, вращение — изменение. Удержание 1,2–3,5 с и отпускание — пуск/пауза/продолжение; от 3,5 с и отпускание — явное сохранение без смены состояния воспроизведения.
- Общие масштаб, 8 ориентаций, угол 0…359°, скорость 25…400%; отдельная пауза между циклами каждой программы. Gap 0 теперь означает непрерывный повтор. Нет прежних 200 мс стоянки Frame и таймаута калибровки.
- Show начинает цикл с 10 проходов камня; Stone повторяет только камень. Сохраняются выбранная программа по умолчанию и переключаемый на панели авторежим; отсчёт старта 5 с с отменой.
- Изменения геометрии выполняются с гашением и перемещением к предыдущей вершине. Пауза и переключение параметров не сбрасывают Show. Автосохранение удалено; запись NVS только явно и при погашенном луче.
- Угловой поворот вписывает рамку в цифровое поле: при 45° применяется ~0,707 от заданного масштаба; status показывает оба значения. При 0° диапазон сохранён. DAC gain остаётся 1×; уменьшение физического изображения пока не объяснено измерениями.
- Миграция проверенного старого профиля сохраняет фактический масштаб/ориентацию. Отдельные старые диагностики заменены на Frame с выключенным автостартом. GPIO, массивы рисунков и шрифт сохранены.

## 0.1.3 — 2026-10-30

- Видимая калибровка Frame: квадрат полного цифрового поля + большая F; глобальные масштаб/ориентация меняются по проекции.
- В Frame короткое нажатие переключает Scale/Orientation, при нажатой кнопке луч погашен, удержание 1,2 с завершает калибровку. Таймаут 60 с без ввода. Поведение обычного Show «нажал — остановил» сохранено.
- Геометрия фиксируется на полный проход и обновляется перед тёмным перемещением; между проходами 200 мс без луча.
- Frame — четвёртая программа; белые 4 и фиолетовые 8 значения теперь идут по соседним диодам. Калибровка не стартует автоматически от питания.
- Проверка полного Show внутри рамки при 5/25/50/100%; старые рисунки, декодер энкодера, Geometry и Motion сохранены. Агент прошивку не загружал; проекцию проверяет владелец.

## 0.1.2 — 2026-10-30

- Автономная панель: энкодер CLK/DT/SW, антидребезг, меню программы/масштаба/ориентации/паузы. Удержание 1,2 с запускает выбранный рисунок; нажатие во время рисования или паузы останавливает без повторного старта тем же жестом.
- NeoPixel через аппаратный асинхронный RMT; индикация меню, работы, паузы и ошибки; ledtest. Число пикселей настраивается (по умолчанию прежние 12).
- Профиль в Preferences/NVS, запись только при остановке; режимы ручного запуска и явно включаемого boot auto с отменяемым отсчётом 5 с.
- Show повторяется после настраиваемой тёмной паузы (10 с по умолчанию, gap 0 — один цикл); preview не повторяется, тесты по 10 с.
- USB status/monitor с ограниченной очередью, без ожидания компьютера. Wi-Fi пока не добавлен.
- Данные, шрифт, ShowPlayer, Geometry и Motion побайтово сохранены. Новая панель и оптический результат требуют проверки владельцем; агент не загружал прошивку.

## 0.1.1 — 2026-10-29

- Переключение 8 ориентаций через USB; orient 0 сохраняет старый вывод, orient 2 — первый вариант по описанию отражения слева/справа.
- Асимметричный тест F; квадрат сохранён.
- Отдельные blankoff/settle, гашение перед тёмным движением и ожидание перед включением луча. Начальные 500/1500 мкс — параметры настройки, не измеренные задержки оборудования.
- Преобразование применяется к целям до интерполяции, текущая физическая позиция при смене ориентации сохраняется.
- Данные рисунков/шрифта, GPIO и DAC gain не изменены. Старый скетч сохранён.
- Сборка и проверки настоящего кода прошли; [инструкция](0.1.1/README.md), [протокол](0.1.1/BUILD.md). Агент не загружал прошивку; оптический результат 0.1.1 не проверен.

## 0.1.0 — 2026-10-15

- Первая одноконтроллерная версия для XIAO ESP32-S3 Plus и EPLZON v0.7.
- MCP4822 SPI/парное LDAC, внешний MOSFET, совместимость с HCT245/AHCT245 при 5V.
- Перенесены данные 98 рисунков, векторный шрифт и 248 шагов исходного RP2040-плеера без UART.
- Без энкодера и NeoPixel; диагностический квадрат, preview, ручное разрешение луча, show, stop и масштаб через USB.
- По умолчанию луч выключен, автозапуск отключён. Физическая проверка новой платы ещё не выполнена.
