# Data flow

1. `touchdesigner/legacy/IMG READY/law_196.png`, law_197.png and law_200.png are the external image inputs named by the 2025 `sop_tracer_to_short_unsigned` component. Its SOP/replicant network exposes points, vertices and primitives DATs.
2. `trace_all` exports named unsigned-short arrays to `string_to_send`. It scales normalized positions by 4095, emits an off/on pair at each primitive's first coordinate, traverses vertices with bit 15 set, conditionally closes a contour, and ends off at the first coordinate. It rejects negative coordinates but has no upper clamp. The alternate `trace_all_with_distance` adds an off point at the previous coordinate for gaps >25; the next coordinate is still on, so this does not implement an off-state travel to the destination under the receiver's semantics.
3. The preserved Cuneiform.h is a manually incorporated generated artifact. These DAT scripts explain the representation, but an exact regeneration recipe and parameter state for the whole header are not proven. Embedded generated output in the TOE is not assumed to equal the whole final header.
4. Player sketch references arrays directly and schedules text; its included Cuneiform.h is mandatory. Cuneiform_stable.h and Choreography.h are preserved sibling artifacts but not included by the selected fulltexts sketch.
5. The player subdivides/sends UART packets; Uno decodes, draws text or applies point state and transforms; SPI updates DAC A/B, LDAC synchronizes the pair, and D5 controls blanking.

Earlier route: root `script` DAT generates timed hexadecimal commands with distance-based subdivision (10 coordinate units/frame); `scripts` DAT streams and records packets using absolute frame numbers. `Version 2025/Recorded Choreography/null6.py` is timestamp/packet text despite its extension, not a normal Python program. The older Hammurapireads uses recorded Choreography.h. Those are separate routes; neither is silently substituted for the compiled fulltexts choreography.

External Python experiments are in `tools/legacy-generators`. GCODEtoUnsigned parses S1000/S0 and XY, scales using a supplied factor, clamps to 0–4095, and emits pairs. Its if/elif structure skips coordinates on lines containing S1000/S0; modal single-axis G-code is not fully supported. SVG experiments use segment endpoints only, multiply by 4096 without normalization/clamping, and attach on to the start/off to the endpoint. `script_simplify.py` skips segments by index; it is not a geometry-preserving simplifier. These are historical utilities, not verified generators for the latest artwork. Do not run them on the preserved header.
